# Tenant 360 Page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only tenant detail page at `/tenants/:id` showing details, KPIs, four charts, invoices, and a statement ledger — opened by clicking a tenant row.

**Architecture:** One new read-only aggregate endpoint `GET /api/tenants/:id/overview` computes KPIs + chart series server-side; the invoices table and statement ledger reuse existing endpoints. A new React page renders it. Nothing else changes; the page has no write paths.

**Tech Stack:** Perl/Dancer2 + DBIx::Class (backend), React 19 + Ant Design 6 + TanStack Query + Recharts (frontend), `prove` (backend tests).

**Spec:** `docs/superpowers/specs/2026-08-10-tenant-360-page-design.md`

## Global Constraints

- Read-only. No new mutations, no schema changes.
- Backend tests run **only inside the Docker backend container**: from repo root, `docker compose run --rm -T backend prove -l t/...`. The DB is up and migrated. Test output has pre-existing noise (a DBIC driver dump, a `sql_limit_dialect` warning) — judge TAP ok/not-ok only.
- Money/number display uses the existing `formatCurrency` / `formatDate` (`ro-RO`). No `Co-Authored-By` trailers.
- Frontend has ~17 pre-existing eslint warnings and 0 errors; keep errors at 0. `npm run lint` and `npm run build` must pass.
- A metered-consumption period with **no reading is `null` (a gap), never `0`**.

```perl
# GET /api/tenants/:id/overview - read-only analytical read-model for tenant 360
get '/:id/overview' => sub {
    my $auth_error = require_auth();
    return $auth_error if $auth_error;

    my $tenant = schema->resultset('Tenant')->find(route_parameters->get('id'), {
        prefetch => 'utility_percentages',
    });
    unless ($tenant) {
        status 404;
        return { success => 0, error => 'Tenant not found' };
    }

    # --- tenant block ---
    my %tenant_data = $tenant->get_columns;
    $tenant_data{utility_percentages} = [
        map { { utility_type => $_->utility_type, percentage => $_->percentage + 0,
                uses_meter => $_->uses_meter ? 1 : 0 } }
        $tenant->utility_percentages->all
    ];

    # --- invoices -> KPIs + payment behaviour ---
    my @invoices = schema->resultset('Invoice')->search(
        { tenant_id => $tenant->id }, { order_by => 'invoice_date' }
    )->all;

    my $days_between = sub {
        my ($from, $to) = @_;                       # 'YYYY-MM-DD' strings
        return undef unless $from && $to;
        my @a = $from =~ /^(\d{4})-(\d{2})-(\d{2})/ or return undef;
        my @b = $to   =~ /^(\d{4})-(\d{2})-(\d{2})/ or return undef;
        my $d1 = DateTime->new(year=>$a[0], month=>$a[1], day=>$a[2]);
        my $d2 = DateTime->new(year=>$b[0], month=>$b[1], day=>$b[2]);
        return $d2->delta_days($d1)->in_units('days') * ($d2 >= $d1 ? 1 : -1);
    };

    my ($billed, $paid, $open_count) = (0, 0, 0);
    my (@pay_points, @pay_lags, @overdue_days);
    my $today = DateTime->now->ymd;
    for my $inv (@invoices) {
        my $amt = $inv->total_ron + 0;
        $billed += $amt;
        if ($inv->is_paid) {
            $paid += $amt;
            if ($inv->paid_date) {
                my $lag = $days_between->($inv->invoice_date . '', $inv->paid_date . '');
                if (defined $lag) {
                    push @pay_points, { invoice_date => $inv->invoice_date . '', days_to_pay => $lag };
                    push @pay_lags, $lag;
                }
            }
        } else {
            $open_count++;
            my $ref = ($inv->due_date // $inv->invoice_date) . '';
            my $od = $days_between->($ref, $today);
            push @overdue_days, $od if defined $od && $od > 0;
        }
    }
    my $avg_days = @pay_lags ? int(0.5 + (eval { my $s=0; $s+=$_ for @pay_lags; $s } / @pay_lags)) : undef;
    my $oldest   = @overdue_days ? (sort { $b <=> $a } @overdue_days)[0] : undef;

    my %kpis = (
        billed_ron        => sprintf('%.2f', $billed) + 0,
        paid_ron          => sprintf('%.2f', $paid) + 0,
        outstanding_ron   => sprintf('%.2f', $billed - $paid) + 0,
        open_count        => $open_count,
        oldest_unpaid_days => $oldest,
        avg_days_to_pay   => $avg_days,
    );

    # --- utility allocation (finalized calcs only), grouped by utility ---
    my $alloc_rs = schema->resultset('UtilityCalculationDetail')->search(
        { 'me.tenant_id' => $tenant->id, 'calculation.is_finalized' => 1 },
        { join => 'calculation',
          select => ['me.utility_type', { sum => 'me.amount' }],
          as     => ['utility_type', 'total'],
          group_by => ['me.utility_type'] }
    );
    my %alloc;
    while (my $row = $alloc_rs->next) {
        $alloc{ $row->get_column('utility_type') } = sprintf('%.2f', $row->get_column('total') || 0) + 0;
    }
    # keep a 0 bar for utilities the tenant carries a standing rate for
    for my $up ($tenant->utility_percentages->all) {
        $alloc{ $up->utility_type } //= 0 if $up->percentage > 0 || $up->uses_meter;
    }
    my @utility_allocation = map { { utility_type => $_, total_ron => $alloc{$_} } }
        sort keys %alloc;

    # --- metered consumption per utility (gas/water direct; electricity via meters) ---
    my %metered;
    # gas + water
    for my $pair (['gas','GasReading'], ['water','WaterReading']) {
        my ($ut, $rs) = @$pair;
        my @rows = schema->resultset($rs)->search(
            { tenant_id => $tenant->id },
            { order_by => [{ -asc => 'period_year' }, { -asc => 'period_month' }] }
        )->all;
        next unless @rows;
        $metered{$ut} = [ map {
            { period => sprintf('%04d-%02d', $_->period_year, $_->period_month),
              value => defined $_->consumption ? $_->consumption + 0 : undef }
        } @rows ];
    }
    # electricity via this tenant's meters
    my @meter_ids = map { $_->id }
        schema->resultset('ElectricityMeter')->search({ tenant_id => $tenant->id })->all;
    if (@meter_ids) {
        my @rows = schema->resultset('MeterReading')->search(
            { meter_id => { -in => \@meter_ids } },
            { order_by => [{ -asc => 'period_year' }, { -asc => 'period_month' }] }
        )->all;
        $metered{electricity} = [ map {
            { period => sprintf('%04d-%02d', $_->period_year, $_->period_month),
              value => defined $_->consumption ? $_->consumption + 0 : undef }
        } @rows ] if @rows;
    }

    # --- data completeness ---
    my @empty;
    for my $f (qw(cui_cnp j_number postal_code phone email contract_start contract_end notes)) {
        my $v = $tenant->get_column($f);
        push @empty, $f unless defined $v && $v ne '';
    }
    my %data_completeness = (
        empty_fields => \@empty,
        not_modelled => [qw(deposit area_sqm lease_term signed_contract contact_person iban)],
    );

    return { success => 1, data => {
        tenant             => \%tenant_data,
        kpis               => \%kpis,
        payment_behaviour  => \@pay_points,
        utility_allocation => \@utility_allocation,
        metered_consumption => \%metered,
        data_completeness  => \%data_completeness,
    } };
};
```

```jsx
import { Row, Col, Card, Empty, Tag } from 'antd';
import {
  ResponsiveContainer, ScatterChart, Scatter, XAxis, YAxis, CartesianGrid, Tooltip,
  BarChart, Bar, LineChart, Line, Legend,
} from 'recharts';
import { formatCurrency } from '../../utils/formatters';

const UTIL_LABEL = {
  electricity: 'Electricitate', gas: 'Gaz', water: 'Apă',
  salubrity: 'Salubritate', internet: 'Internet', other: 'Altele',
};

const CardBox = ({ title, children }) => (
  <Card size="small" title={title} style={{ height: '100%' }}>{children}</Card>
);

const TenantCharts = ({ overview }) => {
  const { payment_behaviour = [], utility_allocation = [], metered_consumption = {}, data_completeness = {} } = overview;

  const alloc = utility_allocation.map((u) => ({
    name: UTIL_LABEL[u.utility_type] || u.utility_type, total: Number(u.total_ron),
  }));

  // Merge metered series into rows keyed by period, so gaps stay as missing points.
  const utils = Object.keys(metered_consumption);
  const periodSet = new Set();
  utils.forEach((u) => metered_consumption[u].forEach((p) => periodSet.add(p.period)));
  const periods = [...periodSet].sort();
  const consRows = periods.map((period) => {
    const row = { period };
    utils.forEach((u) => {
      const pt = metered_consumption[u].find((p) => p.period === period);
      row[u] = pt ? pt.value : null; // null = gap, never 0
    });
    return row;
  });
  const lineColors = { electricity: '#b8860b', gas: '#d97706', water: '#2563eb' };

  return (
    <Row gutter={[16, 16]}>
      <Col xs={24} lg={12}>
        <CardBox title="Comportament de plată (zile până la plată)">
          {payment_behaviour.length === 0 ? (
            <Empty description="Nicio factură plătită" />
          ) : (
            <ResponsiveContainer width="100%" height={240}>
              <ScatterChart margin={{ top: 10, right: 20, bottom: 10, left: 0 }}>
                <CartesianGrid />
                <XAxis dataKey="invoice_date" name="Emisă" tick={{ fontSize: 11 }} />
                <YAxis dataKey="days_to_pay" name="Zile" tick={{ fontSize: 11 }} />
                <Tooltip cursor={{ strokeDasharray: '3 3' }} />
                <Scatter data={payment_behaviour} fill="#b8860b" />
              </ScatterChart>
            </ResponsiveContainer>
          )}
        </CardBox>
      </Col>

      <Col xs={24} lg={12}>
        <CardBox title="Alocare utilități (RON)">
          {alloc.length === 0 ? (
            <Empty description="Fără alocări finalizate" />
          ) : (
            <ResponsiveContainer width="100%" height={240}>
              <BarChart data={alloc} layout="vertical" margin={{ left: 20, right: 30 }}>
                <CartesianGrid horizontal={false} />
                <XAxis type="number" tick={{ fontSize: 11 }} />
                <YAxis type="category" dataKey="name" width={90} tick={{ fontSize: 11 }} />
                <Tooltip formatter={(v) => formatCurrency(v)} />
                <Bar dataKey="total" fill="#b8860b" />
              </BarChart>
            </ResponsiveContainer>
          )}
        </CardBox>
      </Col>

      <Col xs={24} lg={12}>
        <CardBox title="Consum contorizat">
          {utils.length === 0 ? (
            <Empty description="Chiriaș necontorizat" />
          ) : (
            <ResponsiveContainer width="100%" height={240}>
              <LineChart data={consRows} margin={{ top: 10, right: 20, left: 0 }}>
                <CartesianGrid />
                <XAxis dataKey="period" tick={{ fontSize: 11 }} />
                <YAxis tick={{ fontSize: 11 }} />
                <Tooltip />
                <Legend />
                {utils.map((u) => (
                  <Line key={u} type="monotone" dataKey={u} name={UTIL_LABEL[u] || u}
                    stroke={lineColors[u] || '#888'} connectNulls={false} dot />
                ))}
              </LineChart>
            </ResponsiveContainer>
          )}
        </CardBox>
      </Col>

      <Col xs={24} lg={12}>
        <CardBox title="Completitudine date">
          <div style={{ marginBottom: 8, color: 'var(--pm-color-text-secondary)' }}>Necompletate</div>
          <div style={{ marginBottom: 12 }}>
            {(data_completeness.empty_fields || []).length === 0
              ? <Tag color="green">Complet</Tag>
              : (data_completeness.empty_fields || []).map((f) => <Tag key={f}>{f}</Tag>)}
          </div>
          <div style={{ marginBottom: 8, color: 'var(--pm-color-text-secondary)' }}>Nemodelate în sistem</div>
          <div>{(data_completeness.not_modelled || []).map((f) => <Tag key={f} color="default">{f}</Tag>)}</div>
        </CardBox>
      </Col>
    </Row>
  );
};

export default TenantCharts;
```
